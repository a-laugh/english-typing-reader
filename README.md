# 键学 · 用键盘学英语

**在线使用：<https://a-laugh.github.io/english-typing-reader/>**

跟着 BBC《6 Minute English》练英语打字：内容每周自动更新，打开网页就能用，无需注册登录。

## 怎么玩

1. 打开[网站](https://a-laugh.github.io/english-typing-reader/)，在下拉框选择一期节目
2. 看着对白，**直接敲键盘**逐字符输入当前高亮的单词
   - 敲对：字母变绿，自动前进
   - 敲错：字母标红并短响一声，**原地重打**即可（不用退格）
   - 词内符号也要敲（如 `we've` 的 `'`、`six-minute` 的 `-`）；句尾标点不用敲
3. 敲完一个词：自动朗读发音，并在**单词上方**弹出简洁中文释义
4. 换行继续，直到打完整期节目 🎉

## 功能特性

- **对话式展示**：按主持人对话回合排列，说话人彩色徽章标识
- **最新内容**：节目取自 BBC 官网最近 30 天（BBC 每周四更新一期），每周日凌晨自动上新
- **语境释义**：优先给出 AI 结合上下文翻译的简洁中文（不超过 10 字）；BBC 官方词汇表的词由 AI 参照官方释义翻译
- **真人感发音**：每个单词的发音提前生成，打完即响、无需等待
- **自动续学**：进度保存在你的浏览器里，下次打开自动从上次的位置继续；换一期节目互不影响
- **多人可用**：各自浏览器各自进度，互不干扰
- **手机也能用**：点击页面任意位置即可唤起键盘

## 常见问题

**Q：进度存在哪里？换台电脑还在吗？**
进度保存在当前浏览器的本地存储中（无需账号）。同一浏览器关掉再开进度还在；换浏览器或设备则不共享。

**Q：有的词显示「未收录」？**
释义只覆盖值得学的非常用词（含每期官方词汇表）。the、and 这类基础词不再翻译。

**Q：节目列表为什么只有几期？**
内容滚动保留最近 30 天，过期节目自动下线（BBC 每周四更新一期，通常在架 4-5 期）。

**Q：没声音？**
确认浏览器没有静音；极少数浏览器不支持自动播放，可先点击一下页面再开始输入。
